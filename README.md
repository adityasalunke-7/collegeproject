# Shri Sai Seva Clinic — Field Project

A responsive, frontend-only clinic website made as a college field project by Yash Patil. The accompanying presentation records 45 hours of work in September 2026.

## Open the website

Open `index.html` in a browser, or visit the GitHub Pages site:

https://adityasalunke-7.github.io/collegeproject/

## Clinic information

The clinic identity, signboard photo, phone number, practice description and hours shown here are taken from the supplied field-project presentation. The signboard lists morning hours from 10:00 am to 1:00 pm and evening hours from 6:00 pm to 11:00 pm. Call 88888 88575 to confirm before visiting. The presentation does not specify a street address.

## Pages and features

- Home page with clinic details and services
- About page with the supplied clinic signboard photo
- Appointment request demo
- Patient login and signup demo
- Responsive layout for desktop and mobile

The website uses HTML, CSS and JavaScript. Demo data is stored only in the current browser's local storage. Appointment requests do not reach the clinic, and patient account pages are not connected to real authentication. Do not enter real or sensitive information.

# Vimal Clinic

A responsive, frontend-only clinic website suitable as a college project demo. It uses plain HTML, CSS and JavaScript; its demo account and appointment data are stored in the current browser's local storage.

## Run locally

Open `index.html` directly in a browser. No server, Node.js or installation is required.

## Features

- Responsive home and about pages
- Patient registration and sign-in demo
- Appointment request form
- Demo data saved in browser local storage on this device

## API examples

This is an educational demo. Data is stored only in the browser where the site is opened; it is not sent to the clinic or shared between devices. Do not use it for real patient accounts or medical data.
